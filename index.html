Audio and MIDI to Desmos

Turns a MIDI file, or the main melody of an MP3 or WAV, into a Desmos formula you can paste straight into a cell, then play with Desmos Audio Trace. No developer tools or bookmarklet needed. A full song (up to 5 minutes) is turned into one single Desmos equation automatically. At each moment it follows the loudest of the bass, mid and lead parts. No files to save.

Drop a MIDI, MP3 or WAV file here
or tap to choose a file
Play it in Desmos
  1. Open desmos.com/calculator. In graph settings, set both X and Y to exactly 0 to 100, and don’t zoom or pan afterwards.
  2. Paste the formula into an empty expression cell.
  3. Select the formula so it is highlighted.
  4. Press Alt+T (Option+T on Mac or iPad keyboard) to turn on Audio Trace. Set the tempo with Alt/Option+1 to 5.
  5. Press H to play.
Audio Trace uses keyboard shortcuts, so on an iPad you need a hardware keyboard. Optional: load it with one tap (bookmarklet) If pasting gives errors, this inserts the copied formula using Desmos’s own API (the same method img2desmos uses) and sets both axes to 0 to 100 for you. Copy the formula, open desmos.com/calculator, run the bookmarklet, paste into the box it shows, and tap Load. Use the Standard (LaTeX) format with it.
